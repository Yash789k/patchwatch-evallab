# PatchWatch EvalLab 1.0.0

First complete release of the local Python dependency maintenance and evaluation product.

- Inspect, discover releases, plan, approve, and verify constrained dependency upgrades.
- Curated Pydantic and SQLAlchemy migrations with fixed Docker checks and protected tests.
- Eight reproducible evaluation scenarios, independent graders, and CI regression gates.
- Portable evidence workspace with real benchmark runs, diffs, logs, plans, and traces.
- Installable Python wheel and source distribution; all 13 architecture diagrams in Mermaid.
- No model API, cloud database, or paid hosting requirement. GPL-3.0-only.

See the README for installation, support limits, measured outcomes, and the security model.
